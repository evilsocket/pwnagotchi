# Pwnagotchi Enhanced

This project is an enhanced version of [Pwnagotchi](https://github.com/evilsocket/pwnagotchi), created by [@evilsocket](https://twitter.com/evilsocket) and the [amazing dev team](https://github.com/evilsocket/pwnagotchi/graphs/contributors).

## Original Project
Pwnagotchi is an [A2C](https://hackernoon.com/intuitive-rl-intro-to-advantage-actor-critic-a2c-4ff545978752)-based "AI" leveraging [bettercap](https://www.bettercap.org/) that learns from its surrounding WiFi environment to maximize the crackable WPA key material it captures.

## This Enhanced Version
This repository contains an enhanced version of Pwnagotchi with the following improvements:
- Modernized dependencies
- Enhanced security features
- Improved AI/ML capabilities
- Better performance optimizations
- Extended feature set

See [improvements.md](improvements.md) for a detailed roadmap of planned and implemented improvements.
